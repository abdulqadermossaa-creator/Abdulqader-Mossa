مبادئ التصميم

🧩

Plug and Play

كل مضيف يُضاف من الداشبورد بضغطة زر. لا تغيير في الكود. كل شيء يشتغل تلقائياً من اللحظة الأولى.

  • نموذج واحد لإضافة أي مضيف
  • إعدادات افتراضية ذكية
  • تفعيل فوري بدون إعادة تشغيل
🔧

Feature Modules

كل ميزة معزولة في module مستقل. تفعّله أو توقفه لأي مضيف دون أن يأثر على الباقين.

  • 🏆 Sports: دوري السعودية، أوروبا، إلخ
  • 🎵 Music: النوع، التوقيت
  • 💡 Lighting: مشاهد، تعتيم تلقائي
  • 🤖 AI: شخصية، لغة، تفضيلات
⚙️

Per-Host Config

مضيف A يريد مباريات دوري السعودية فقط وموسيقى عربية. مضيف B لا يريد رياضة أصلاً. كل واحد مستقل تماماً.

  • JSON config لكل مضيف
  • يُحفظ في Supabase
  • يُحمّل عند أي حدث
📊

Supabase Backend

Auth · Database · Realtime · Storage كلهم جاهزين. ما تحتاج تبني backend من الصفر.

  • hosts table
  • events table (logs)
  • automations table
🔄

Automation Graph

كل حدث → قائمة أتمتة. كل مضيف يحدد أي أتمتة تشتغل عنده. التعديل من الداشبورد مباشرة.

  • CHECKIN_STARTED → welcome routine
  • PROPERTY_EMPTY → reset all
  • CHECKOUT_SOON → reminders
🌐

Booking Sources

Airbnb · Booking.com · مباشر. كل مصدر يُرسل BOOKING_CREATED للـ Event Bus والنظام يكمل وحده.

  • Webhook لكل مصدر
  • توحيد البيانات
  • State Engine يتحدث تلقائياً

مخطط قاعدة البيانات

hosts (id, name, location, type, status, config JSON, created_at)
events_log (id, host_id, event_type, payload JSON, triggered_at)
automations (id, host_id, trigger_event, actions JSON, is_active)
devices (id, host_id, device_type, zigbee_id, last_seen)
bookings (id, host_id, source, guest_name, checkin, checkout, status)
